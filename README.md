# 🌟 MR DEVIL BOT v2.0

Facebook Messenger Bot — Powered by **Mrdevilfca** (`github:MRDEVIL786143/Mrdevilfca`)

## Setup

1. `npm install`  (FCA apni repo se GitHub se install hogi)
2. `config.json` mein `ADMINBOT` aur `AI_OWNER_UID` mein apna Facebook UID daalo
3. `bot_connect/appstate.json` mein apna appstate paste karo
4. `npm start`

## Notes

- Commands folder: `MrDevil/commands`, events folder: `MrDevil/events`
- Web panel: `PORT` (config.json) par chalta hai
- FCA badalni ho to `package.json` mein `Mrdevilfca` wali line ka link badlo (naam `Mrdevilfca` isliye rakha hai taaki baaki code na toote)
